# Bank Logos

This folder is the source of truth for bank logos used by the account input UI.

## How to replace with official logos

1. Keep the same filenames below.
2. Replace each file with the official bank logo asset.
3. Keep a square canvas and transparent background when possible.
4. Prefer `SVG`; if not possible, use high-resolution PNG.
